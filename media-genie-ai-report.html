1. Executive summary

Media Genie AI is an AI-powered visual library and portfolio builder. Users upload images; AI tags, scores, and captions them; then a natural-language prompt produces a shareable public portfolio URL.

The live deployment sits on Vercel under Ram Badrinathan’s team and is used in practice for KarmYog Vatika project imagery (bamboo, gardens, construction, events). Internally it is catalogued under vatika.ai / mediagenie.ai.

Pitch: “Stop organizing photos by hand. Start shipping portfolios in seconds.”
Claimed value: ~3 hours of folder hunting → under 2 minutes to a shareable link.

3. User journey (as marketed)

  1. Upload — drag/drop from phone/laptop/camera; up to 20 MB/image; bulk upload; no separate cloud account required.
  2. AI analysis — Claude Vision claimed; outputs tags, quality score 0–10, caption, dominant colors, scene type.
  3. Prompt → portfolio — e.g. “best project shots for investor pitch”; system selects, orders, captions, returns shareable link.

Landing CTAs: “Try it now” → /review · “See a live portfolio” → demo gallery.
